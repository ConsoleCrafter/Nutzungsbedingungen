Privacy Policy

Datenschutzerklärung

1. Controller

[YOUR NAME], [YOUR ADDRESS / COUNTRY], [YOUR E-MAIL]. The bot is operated privately on a self-managed server.

2. Data we process and why

  • Server settings: server ID, log channel ID and the on/off state and limits of each protection. Stored permanently in a configuration file so the bot works after restarts.
  • Message content: read in real time to apply the word filter and commands. A temporary copy of recent messages (up to 1,000 per channel) is kept in memory only, to produce deletion and channel-deletion logs. It is lost when the bot restarts and is never written to a database.
  • User and event data: Discord user IDs, usernames, role and audit-log information about bans, kicks, timeouts, channel and webhook changes, used to detect abuse and apply sanctions.
  • Violation counters: a per-user counter for the word filter, kept in memory and reset after 24 hours without a violation or on restart.
  • Moderation log: if a server sets a log channel, the bot posts there: deleted messages (author, channel, content, attachment links, as embed and text file), purge transcripts, sanctions and moderator actions. These posts are stored by Discord inside that server and controlled by its administrators.
  • Technical logs: an operational log on the host (errors, bot start, sanctions with user names and IDs). It is rotated when it grows too large.

Legal basis (GDPR): legitimate interest in protecting communities from abuse (Art. 6(1)(f)); for server administrators who configure the bot, performance of the service they request (Art. 6(1)(b)).

3. Sharing

We do not sell data and do not share it with third parties. Data is exchanged only with Discord, the platform the bot runs on, under Discord's Privacy Policy.

4. Retention

Message copies and violation counters exist only in memory. Server settings are kept while the bot is on the server and are deleted on request. Technical logs are kept briefly. Logs posted to a server's log channel remain until that server deletes them.
